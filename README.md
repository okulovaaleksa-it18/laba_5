## Задание 3.10. Список. 

Программа проходит по списку и оставляет только первые появившиеся числа, а все повторяющиеся удаляет.

В классе создаём пустой набор (HashSet), куда будем записывать все числа, которые встречаются.
Проходим по списку по очереди с помощью Iterator, для каждого числа проверяем:
Если числа ещё нет в наборе - оставляем его в списке и добавляем в набор.
Если число уже есть в наборе - значит это повтор, и мы его удаляем из списка.

## Задание 4.10. Мап. 

Нужно реализовать программу, которая подсчитывает результаты соревнований по многоборью. Каждый спортсмен участвует в нескольких видах спорта, за каждый вид спорта он получает определённое количество баллов.
Нужно посчитать сумму баллов каждого спортсмена, отсортировать спортсменов и присвоить место.

Каждый спортсмен сохраняется в Мап, где ключ - полное имя спортсмена, значение - массив баллов по каждому виду спорта
Используется LinkedHashMap, чтобы порядок ввода сохранялся. Мап превращается в список записей, чтобы можно было сортировать. Сортировка происходит по сумме баллов спортсмена в порядке убывания.
